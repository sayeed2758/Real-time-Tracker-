# Screen Time — Life Time

A premium, mobile-first screen-time awareness PWA built with plain HTML, CSS and JavaScript.

## Included
- Daily / weekly / monthly / yearly screen-time calculations
- Manual daily input with local history
- Optional age, sleep and work/study inputs
- Lifetime projection
- 7-day chart and today-vs-prior-average signal
- What-if reduction simulator
- 24-hour time breakdown
- Goal, streak and achievements
- In-app live session timer
- Daily date-based motivational quotes
- Share quote / install app actions
- Light / dark theme
- Offline PWA service worker
- LocalStorage-only privacy model

## Device screen-time note
A normal GitHub Pages website cannot read Android's system-wide Digital Wellbeing totals directly. The dashboard therefore uses manual device screen-time input plus a clearly labeled in-app session timer.

## Run
Open `index.html` in a browser or deploy the folder to GitHub Pages.

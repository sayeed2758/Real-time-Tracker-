# Screen Time • Life Time

Premium, mobile-first PWA for tracking daily screen time and translating it into weekly, yearly and lifetime views.

## Features
- Daily screen-time input with age, sleep and work/study context
- 7-day pulse chart, monthly totals and daily streaks
- Life-time projection and 24-hour day breakdown
- What-if reduction simulator and reclaimed-time metrics
- Achievements, history, daily quote rotation and focus tips
- In-app live session timer (website-open time only)
- Light/dark theme
- Installable PWA and offline shell
- Local-only browser storage; no backend required

## Important
A normal GitHub Pages website cannot read Android Digital Wellbeing system-wide usage directly. Enter the device's actual total manually; the in-app timer is only for time spent inside this app.
